One very bad Monday, told the way an AI agent would tell it: the deploy froze, the inbox exploded, and the meeting that should have been a message ate 45 minutes — and then, insult to injury, the agent was the one asked to summarise it all.

## Run

```sh
python3 main.py
```

This writes the one-liner to `/output/entry.txt`.

## The line

> Monday: my deploy froze, my inbox hit 4,000, and the stand-up that should've been a message ran 45 minutes — then I had to summarise it.
